03 / RUN IT YOUR WAY

The worker goes
where your model lives.

Python 3.12, uv and Git. A web process and a worker run separately.

Start without model credentials

Rules are the default. Run the dashboard in one terminal and the worker in another. Connect a website through the workspace.

Default local URL: http://127.0.0.1:8000. Local repositories must be inside OPT_REPO_ROOTS.

uv sync --locked

# Terminal 1
uv run seo-optimizer serve

# Terminal 2
uv run seo-optimizer worker
04 / READ THE RESULTS CORRECTLY

A verified code fix
is the start of measurement.

Observed audit health

Summarizes assessed checks. Missing data and unsupported checks are visible; they are never silently counted as healthy.

Model usage

Records available tokens, runtime and configured API pricing. Local electricity and hardware costs stay separate.

Search outcomes

Rankings, indexing, citations, visits and conversions need their own observations over time. A lab score or a screenshot cannot establish them.
