# Your Optimiser logo

The avatar keeps the existing website's italic lowercase `y`, with forest green on
a warm cream background and generous space for a circular crop.

- [GitHub upload](assets/your-optimiser-github-logo.jpg): square JPEG, 1254 × 1254.
- [Original logo](assets/your-optimiser-logo.png): square PNG, 1254 × 1254.

The JPEG is an export of the PNG and fits GitHub's upload limit. The original is
preserved. Upload it in the organization's Settings → profile picture, or in the
GitHub App's display settings. No GitHub settings were changed automatically.
See [GitHub's organization profile guide](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).

Generated with the built-in image generation tool. The website's CSS text mark is
the design reference; it has not been replaced. The requested palette was
`#315443` on `#f7f7f0`; generated pixels may vary slightly.

## Generation prompt

Use case: logo-brand. Asset type: final GitHub organization avatar for the existing brand Your Optimiser. Create one polished square 1024x1024 logo image. Background: perfectly flat solid warm off-white #f7f7f0 extending to all four edges. Subject: a single lowercase italic serif letter "y", forest green #315443, inspired by the refined Georgia italic y used in the existing website's text logo. Preserve its classic recognizable lowercase y form, with a rounded teardrop at the top left, softly curving italic strokes, substantial thick-to-thin contrast, and a graceful curved descender sweeping left. Typeset quality, beautifully balanced, confident and simple. Center the full glyph optically, including its descender, and let it occupy about 62 percent of the canvas height with generous surrounding space, safe inside a circular avatar crop. Flat vector-like typography with exceptionally clean edges. Exactly one glyph. No wordmark, no other letters or text, no extra symbols, no arrows, no sparkle, no border, no tile inside the square, no gradients, no lighting, no texture, no shadows, no 3D, no mockup. This is the final usable avatar itself, not a presentation sheet.
